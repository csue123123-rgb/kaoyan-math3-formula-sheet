# 考研数学三 · 公式参考表

LaTeX 排版的考研数学三公式总结，覆盖**高等数学、线性代数、概率论与数理统计**三大部分，共 60+ 个知识点小节，附常用函数图像。适合作为冲刺阶段的公式速查手册。

## 内容板块

**第一部分 · 高等数学**

常用初等恒等式与因式分解、基本不等式与均值不等式、三角函数公式（同角/和差/倍半角、和差化积）、两个重要极限、等价无穷小、极限运算法则、导数与微分、高阶导数与莱布尼茨公式、微分中值定理、泰勒/麦克劳林展开（含收敛域）、洛必达法则、函数性态（单调/极值/凹凸/拐点/渐近线）、经济应用（边际/弹性/连续复利）、基本积分公式、换元与分部积分、定积分性质、变上限积分、反常积分、定积分应用、多元函数微分与极值（含拉格朗日乘数法）、二重积分、常数项级数判据、幂级数、一阶/二阶微分方程、差分方程等

**第二部分 · 线性代数**

行列式（定义/展开/性质/特殊行列式）、矩阵运算与逆矩阵、伴随矩阵、矩阵的秩、初等变换与初等矩阵、分块矩阵、向量组的线性表示与相关性、极大无关组与秩、内积与施密特正交化、线性方程组解的结构与判定（含参数讨论通法）、特征值与相似对角化、实对称矩阵性质、二次型及其矩阵等

**第三部分 · 概率论与数理统计**

随机事件与概率、常见分布、数字特征、参数估计（矩估计/最大似然估计）、假设检验（附 Z / t / χ² 检验判定表与两类错误）等

**附**：常用函数图像——幂函数、指数对数函数、反三角函数、正态分布曲线

## 本地编译

需要 XeLaTeX + ctex 宏包（TinyTeX / TeX Live / MiKTeX 均可，本文档在 TinyTeX 下用 xelatex 编译通过）。

**Windows**：双击 `build.bat`

**或手动**（建议编译两遍，保证交叉引用与目录正确）：

```bash
xelatex 考研数学303公式参考表_数三.tex
xelatex 考研数学303公式参考表_数三.tex
```
